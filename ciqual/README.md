# Ciqual

Le repo conserve uniquement le format XML de la table Ciqual.

Raison : les fichiers XML sont structurés par tables métier et se transforment directement vers SQLite/Drift sans dépendance à un lecteur Excel.

Fichiers conservés :

- `alim_2025_11_03.xml` : aliments
- `alim_grp_2025_11_03.xml` : groupes et sous-groupes
- `const_2025_11_03.xml` : constituants nutritionnels
- `compo_2025_11_03.xml` : valeurs nutritionnelles par aliment
- `sources_2025_11_03.xml` : sources
