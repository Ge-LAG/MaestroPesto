work / phase10-sources-ouvertes

Enrichissement et fiabilisation par sources ouvertes

Résultat attendu
Des données plus complètes et plus justes, issues de sources en libre accès sans restriction de licence, chaque valeur citant sa source dans l'application ; les estimations internes restent signalées comme telles.
Origine
Mandat PO du 2026-09-26 : « faire le maximum sur les différents aspects de la base de données, sans les licences (uniquement du libre accès), en autonomie et en citant les sources dans l'app ». Sources à usage non commercial (FlavorDB, FooDB, FAO/INFOODS) écartées.
Livré
Nutrition : USDA FoodData Central (CC0) pour 40 ingrédients absents de Ciqual (glucides hors fibres et énergie UE recalculés) ; 29 préparations de base et substances pures calculées (roux, mirepoix, levains, polyols, acides ; annexe XIV UE) ; audit des 518 rapprochements Ciqual et correction de 24 erreurs (ac-130) ; couverture 518 → plus de 580 ingrédients. pH : liste FDA/CFSAN 2007 (domaine public) extraite, 155 ingrédients rapprochés à la main ; les autres pH sont annoncés « estimation par catégorie » (ils étaient auparavant attribués à tort à la FDA). Portions : poids USDA réels (tasse, cuillère, pièce, gousse, brin, tranche) pour 98 ingrédients, source affichée dans chaque hypothèse de quantité. Cuisson : rétentions USDA RF6 (CC0) pour 63 couples groupe × mode. Accords : 790 accords observés dans les 5 000 recettes d'Escoffier (1907, Project Gutenberg, domaine public), lift ≥ 1,5 et ≥ 6 recettes. Activité de l'eau : coefficient osmotique du sel ; contrôle sur la sauce soja (FDA ITG 39) et une saumure à 10 %. Application : page « Sources des données » (13 sources, licence, usage) et données culinaires sourcées dans la fiche ingrédient. Essai non retenu : le recalage des saveurs sur la composition dégradait la perception (paprika « sucré ») — règle existante conservée.
Point de contrôle
2026-09-26 : commits c9b2f7b → d6d0544 (non poussés) ; flutter analyze 0, dart format propre, flutter test 322/322, flutter build windows --release OK, exécutable lancé sur base isolée : schéma v5, 20 sources importées, 31 234 valeurs nutritionnelles, 1 194 accords, 214 fiches allergènes, 8 recettes. Jeux téléchargés dans tool/.cache/ (exclu du dépôt) : FoodData Central SR Legacy (6,1 Mo) et Foundation Foods (3,8 Mo), RF6 (0,5 Mo), Escoffier (2,1 Mo) ; script tool/fetch_open_sources.sh. En revue : acceptance PO via acceptance-phase10 (étape 13).

Critères d'acceptation machine

Les ingrédients sans entrée Ciqual sont couverts par une source ouverte ou un calcul documenté ; aucun zéro n'est inventé.

Couverture > 580/603 ; shiitake cru USDA ; roux 42 g de lipides ; érythritol 0 kcal ; restent volontairement « non renseigné » les ingrédients sans source fiable (anis étoilé, sumac, pâtes de curry…).

Les rapprochements Ciqual erronés sont corrigés et contrôlés.

Bière sans alcool < 1,5 g d'alcool, fromage frais ≠ fromage de tête, noix > 55 g de lipides, yaourt nature < 4,5 g, confiture > 45 g de sucres, saumon cru peu salé.

Un pH n'est attribué à la FDA que s'il vient de la liste FDA ; les autres sont signalés comme estimations.

155 pH FDA ; tomate 4,3–4,9 citée ; toute autre note commence par « Estimation par catégorie ».

Les conversions d'unités s'appuient sur des poids mesurés et citent leur source.

Gousse d'ail 3 g (USDA FDC), cannelle 0,53 g/ml (USDA FDC) ; hypothèse affichée « 1 pièce ≈ 110 g (USDA FDC) ».

Les accords documentés s'enrichissent d'un corpus du domaine public, cité.

1 194 accords dont > 700 issus du corpus ; cerfeuil × estragon documenté, explication citant Escoffier ; calibration A6 inchangée (benchmarks ≥ 0,70).

L'activité de l'eau des mélanges salés suit les valeurs de référence.

Saumure 10 % : 0,935 ± 0,01 ; sauce soja dans la tolérance (Ciqual moins salée que la sauce mesurée par la FDA).

L'application présente ses sources ; flutter test, flutter analyze et dart format verts ; le build release importe tout.

322/322, analyse propre, page « Sources des données » testée ; release : schéma v5, 20 sources importées, 8 recettes.
