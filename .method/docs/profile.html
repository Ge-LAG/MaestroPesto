Profil projet MaestroPesto

Produit / utilisateurs
Application Flutter local-first de gestion de recettes de cuisine : classeur, recettes liées au référentiel de 603 ingrédients, nutrition Ciqual, compatibilité aromatique, alertes fonctionnelles, recommandations. PO : Guillaume (Ge-LAG). POC desktop Windows ; aucune API réseau (offline).
Stack / carte
Dart ^3.13.1, Flutter (SDK 3.47.1 sur la machine PO), SQLite via Drift. lib/app (shell, thème, i18n), lib/core/{database,models,scoring}, lib/features/{recipes,ingredients,nutrition,flavor,functional,recommendations} en data/domain/presentation. Données : assets/database-metier (CSV phases 1 à 4, source gelée), assets/database-enrichment (ciqual_nutrition.csv généré), ciqual/ (XML 2025-11-03), database/schema.sql, générateurs tool/.
Plateforme
Windows est la cible de build et de smoke test (build/windows) ; macOS/Linux/mobile prévus ensuite. Outil méthode : Python 3.10+, via uv run python .method/tools/method.py sur ce poste (alias Store KO).
Commandes
Depuis la racine : flutter pub get ; flutter test (381 tests attendus verts au 2026-09-29) ; flutter analyze (0 issue) ; dart format --set-exit-if-changed . (exit 0) ; flutter build windows ; flutter run -d windows. Import en app : bouton « Importer BDD métier » (5 phases CSV, idempotent).
Contraintes
database-metier/ est une source gelée : ne pas la modifier ; tout enrichissement passe par tool/ et sort vers assets/database-enrichment/. Pas de secret, token ni donnée réelle au commit ; logs sans chemins utilisateur ni identifiants métier ; XML Ciqual volumineux jamais chargés intégralement en mémoire. Les données manquantes s'affichent honnêtement (décision honest-data-display).
Git / livraison
Origin : github.com/a-langlais/MaestroPesto. main = branche de fusion, jamais un espace de travail ; branches Ge-LAG/ + thème en kebab-case (2-3 mots) ; commits atomiques « theme: resume 2-3 mots ». Push, PR, merge et tag réservés au PO : contrainte delivery-gate.
Langues
Logiciel FR + EN, FR au premier usage ; clés i18n centralisées consommées via context.strings ; conventions dates/nombres FR.
