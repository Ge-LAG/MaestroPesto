Décision : résolution Ciqual par nom

Contexte
Les ciqual_ids du référentiel Phase 1 (assets/database-metier, source gelée) pointent vers une ancienne numérotation Ciqual : dans la table 2025-11-03 renumérotée, le code banane désigne l'abricot (ac-114).
Décision
Le générateur tool/generate_ciqual_enrichment.dart résout PAR NOM tous les ingrédients du référentiel (dp-124, 2026-08-26, retour PO n°4) avec garde-fous durcis : mot-tête obligatoire en match partiel, match complet borné en longueur, exclusions de transformations (jus, zeste, pomme cajou, coco, fourré, mélange), cohérence du mot-tête sauf énumérations et hypernymes, égalité exacte dominante, repli du perdant de collision sur son second candidat, standins curatés manuels (Bœuf vers steak cru, sels, cajou, chèvre frais, chocolat 70 %, café, calvados). Sortie : assets/database-enrichment/ciqual_nutrition.csv — 18 339 records pour 367 ingrédients, chaque valeur avec citation sources.xml et code de confiance ; union avec la Phase 2 : 371/603 couverts.
Alternatives / conséquences
Corriger les ciqual_ids sources : écarté (données métier gelées). Table d'alias manuelle : ouverte, à décider selon l'acceptabilité des approximations (ac-116). Les 221 ingrédients restants sont absents de Ciqual 2025-11-03 : deuxième source sourcée à décider (ac-119).
