constraint / delivery-gate

Contrainte : porte de livraison PO

Invariant
Le PO (Guillaume) est l'unique autorité de livraison : aucun push vers origin, aucune ouverture de PR, merge, tag, ni mutation Git destructrice (reset --hard, rebase d'historique publié, force-push, clean -fd) sans validation explicite du PO dans la session courante. Reconduite des règles V5 R-01/R-02 au passage V6 (2026-09-16).
Hygiène des commits
Commits atomiques au format « theme: resume 2-3 mots » (thème au singulier : ui, ux, backend, db, test, docs, build, method, chore, fix, refactor, feat ; minuscules, sans point final ; jamais de WIP ni de commit fourre-tout ; jamais de secret ou donnée réelle). Diff relu avant staging, pas de git add -A aveugle.
Branches
main est une branche de fusion, jamais un espace de travail : toute évolution passe par une branche Ge-LAG/ + thème kebab-case de 2-3 mots, fusionnée via PR relue par le PO, sans squash ni force-push.
Réutilisation
La validation PO d'une session reste valable dans son périmètre ; une authorization enregistrée peut couvrir un envoi récurrent pendant sa validité.
