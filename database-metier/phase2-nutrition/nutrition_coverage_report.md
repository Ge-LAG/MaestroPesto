## 9. Zones de faiblesse / couverture à étendre
- Acides aminés détaillés : présents dans le dictionnaire, encore peu mappés.
- Aliments fermentés : valeurs nutritionnelles très variables selon recette.
- Variétés botaniques fines (50 cultivars de pomme) : agrégées volontairement.
- Vins et spiritueux : éthanol majeur + micronutriments végétaux.
- Sous-produits carnés (gelatine, abats) : variables ; à compléter.
